AutoFill
Contact and form details are never saved. Use your system password manager for AutoFill.
Saved Logins
No saved passwords yet. Log in on any site and BLACK offers to remember the login.
Passwords are saved locally on this device (obfuscated on disk, not encrypted) and never synced to the cloud. For real encryption, use a dedicated password manager.
Never Save Passwords For
No sites in this list. BLACK will keep offering to save logins everywhere.
BLACK will not autofill or save passwords on these sites. Add a site by clicking “Never for This Site” in the password toast that appears after you log in there.

Account Guest Not signed in
BLACK has no cloud backend — every profile is stored on this device only. Apple/Google cloud sign-in requires a registered OAuth client ID and is not available. Use Private Windows for isolated sessions.
Installed Extensions
No extensions installed. Drop a folder with a manifest.json into the BLACK extensions folder (<AppData>/BLACK/extensions/).
BLACK supports a minimal extension format: content_scripts only. No chrome.* / browser.* API is available yet.
